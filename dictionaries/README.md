# Dictionaries for Yomihon / Словари для Yomihon

В этой директории содержатся предзагруженные словари в формате Yomitan/Yomichan (.zip), а также ссылки для их скачивания и использования в приложении Yomihon.

## Содержимое пакета словарей:

1. **`JMdict_russian.zip`** — Японско-русский словарь
   - **Описание:** Базовый японско-русский словарь терминов и определений на основе проекта JMdict.
   - **Источник:** [yomidevs/jmdict-yomitan](https://github.com/yomidevs/jmdict-yomitan)

2. **`JMdict_english.zip`** — Японско-английский словарь с примерами
   - **Описание:** Полноценный японско-английский словарь терминов с примерами предложений (Tatoeba Project).
   - **Источник:** [yomidevs/jmdict-yomitan](https://github.com/yomidevs/jmdict-yomitan)

3. **`OpenRussian_en_ru.zip`** — Англо-русский / Русско-английский словарь
   - **Описание:** Подробный словарь с переводами, грамматическими формами и определениями для русского и английского языков.
   - **Источник:** [ImenaOphelia/openrussian-to-yomitan](https://github.com/ImenaOphelia/openrussian-to-yomitan)

4. **`Russian_Explanatory.zip`** — Толковый словарь русского языка
   - **Описание:** Одноязычный толковый словарь русского языка с определениями слов и терминов.

5. **`Latin_to_Cyrillic.zip`** — Латиница в Кириллицу (Транслитерация)
   - **Описание:** Словарь и таблица конвертации/транслитерации латинских символов и ромадзи в кириллицу.

## Как установить словари в Yomihon:

1. **Через меню настроек приложения:**
   - Откройте приложение Yomihon.
   - Перейдите в `Настройки` -> `Словари` (`Settings` -> `Dictionaries`).
   - Нажмите кнопку `+` или `Импортировать словарь` и выберите любой из `.zip` файлов в этой папке.

2. **Загрузка в один клик:**
   - В разделе `Рекомендуемые словари` (`Recommended Dictionaries`) нажмите на нужный словарь, чтобы установить его напрямую из приложения.
