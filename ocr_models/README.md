# OCR Models Package / Офлайн-модели OCR для Yomihon

В этой папке содержатся внешние пакеты моделей OCR в формате `.tar.xz` для их использования на устройстве без раздувания размера самого приложения.

## Как установить модели на устройство:

1. Создайте на вашем устройстве папку `Yomihon/OCR` (например: `/sdcard/Yomihon/OCR/` или `/sdcard/Download/Yomihon/OCR/`).
2. Распакуйте или скопируйте нужные файлы моделей (`.tflite`, `.bin`) в папку `Yomihon/OCR`.
3. В приложении Yomihon выберите любую модель в **Настройки -> OCR** или используйте бесплатные ИИ-модели **Zen Free**, **Google AI** или **OpenRouter**.

Если локальные файлы моделей отсутствуют, Yomihon автоматически и без сбоев (без крашей) переключается на онлайн ИИ-модели!
